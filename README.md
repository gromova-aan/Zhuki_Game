# Zhuki_Game

**IP-313 - Громова Анастасия, Широков Кирилл**

Android-приложение «Жуки»: игра, в которой нужно ловить насекомых на время. Реализована регистрация игрока, настройки сложности, таблица рекордов и редактор скинов.

---

## Курсовая работа

**Вариант 10 - Кастомизация внешнего вида жуков: редактор скинов (цвет, размер, текстура, «злые/добрые») и сохранение наборов.**

### Кто что делал

**Кирилл - модель, хранение и игровая интеграция:**

- модель `SkinVariant` / `SkinSet`, перечисления `Texture` и `Mood`, валидация, лимиты, «классический» набор по умолчанию;
- `SkinStorage` + `SkinCodec` + `SharedPreferencesSkinStorage` - сохранение наборов в локальное хранилище;
- `SkinRepository` - CRUD наборов, активный набор, проверка лимитов;
- регистрация зависимостей в Koin (`App.kt`);
- интеграция в `GameViewModel`: при спавне обычного жука выбирается случайный вариант активного набора, применяются цвет, размер, текстура и скорость по настроению;
- тесты данных: `SkinSetTest`, `SkinCodecTest`, `SkinRepositoryTest`, `SkinVariantPickTest`.

**Анастасия - редактор, интерфейс и рендер:**

- `SkinsEditorViewModel` - состояние редактора: наборы, выбранный набор, варианты, черновик;
- экран «Скины» (`SkinsFragment`, `fragment_skins.xml`, списки наборов и вариантов, форма варианта, живой предпросмотр);
- вкладка «Скины» и её иконка в `MainActivity`;
- рендер скинов в `GameFragment`: размер, тинт, текстура, настроение;
- строки интерфейса и иконки настроения;
- тесты редактора: `SkinsEditorViewModelTest`, `SkinTextureMappingTest`;
- README и сценарий проверки курсовой.

### Как проверить курсовую вручную

1. Запустить приложение и открыть вкладку **«Скины»** 
2. Нажать **«+ Новый набор»**, ввести название.
3. Нажать **«+ Вариант»**, выбрать цвет, размер, текстуру и настроение - предпросмотр обновляется сразу.
4. Нажать **«Сохранить»** - вариант появляется в списке вариантов набора.
5. Добавить ещё 2–3 варианта с разными параметрами.
6. Нажать **«Применить набор»** - у набора появится отметка активного.
7. Перейти во вкладку **«Игра»** и нажать **«Старт»**: на поле появляются жуки разных цветов, размеров и текстур из выбранного набора; у «злых» виден бейдж и они двигаются быстрее.
8. Перезапустить приложение и снова открыть «Скины» - наборы и активный выбор сохранились.
9. Проверить, что «Классический» набор нельзя изменить или удалить.

### Ограничения решения

- В наборе 1–10 вариантов, всего до 20 наборов; вариант при спавне выбирается случайно - вручную распределить, «какой жук где», нельзя.
- Текстура выбирается из 5 готовых рисунков или «случайно»; цвет - тинт поверх PNG, а не замена картинки.
- Скины применяются только к обычным жукам. Золотой таракан и бонус не кастомизируются.
- Настроение влияет только на скорость: «злой» - ×1.5, «добрый» - ×1.0. Траектории и поведение не меняются.
- Хранение локальное (SharedPreferences), без синхронизации между устройствами.

## Возможности приложения

Приложение состоит из семи вкладок.

### Регистрация

- выбор существующего игрока или создание нового;
- ФИО, пол, курс, дата рождения, уровень сложности;
- автоматическое определение знака зодиака и показ соответствующей картинки;
- данные игрока сохраняются;
- повторная регистрация не удаляет рекорды.

### Правила

Краткое описание игры и правил начисления очков.

### Авторы

Информация о команде и ссылки на авторов.

### Настройки

- скорость жуков;
- максимальное количество тараканов;
- интервал появления бонусов;
- длительность раунда;
- сохранение и сброс к значениям по умолчанию.

Настройки сохраняются в SharedPreferences и применяются при следующем старте игры.

### Игра

Основной экран с полем, счётом, таймером и кнопкой «Старт/Сброс/Сыграть ещё раз».

### Скины

Редактор наборов и вариантов внешнего вида жуков: цвет, размер, текстура, настроение, предпросмотр, сохранение и применение набора.

### Рекорды

Таблица лучших результатов: имя игрока, сложность, счёт и дата. Рекорд сохраняется для пары «игрок + сложность»; если новый результат хуже, остаётся прежний.

### Виджет курса золота

На главный экран можно добавить виджет «Курс золота ЦБ». Он показывает текущий курс золота Банка России (₽ за грамм), данные загружаются через Retrofit с сайта ЦБ и кэшируются. Курс также используется в игре для начисления очков за золотого таракана.

## Игра

### Старт и завершение

- Нажать **«Старт»** - начинается раунд, счёт обнуляется, запускается таймер.
- Во время игры кнопка превращается в **«Сброс»**: она останавливает раунд и возвращает экран в исходное состояние.
- Когда время раунда заканчивается, игра завершается, счёт сравнивается с рекордом и сохраняется лучший результат.
- После завершения кнопка называется **«Сыграть ещё раз»**.

### Очки

- Клик по обычному жуку - **+1 очко**.
- Клик по пустому месту - **−1 очко** (счёт не уходит ниже нуля).
- Клик по золотому таракану - бонусные очки: текущий курс золота делится на 1000 (минимум 1 очко).

### Жуки и движение

- Жуки двигаются по полю, отскакивают от краёв и разворачиваются по направлению движения.
- Скорость зависит от уровня сложности в настройках.
- Новые жуки появляются взамен пойманных, пока их количество меньше максимума.

### Бонус, наклон и звук

- Периодически появляется золотая звезда-бонус.
- Клик по бонусу включает режим наклона на 10 секунд: жуки начинают реагировать на наклон устройства, а при достижении краёв останавливаются.
- Пока действует режим наклона, звучит крик жуков.
- После окончания режима движение возвращается к обычному.

### Золотой таракан

- Появляется примерно раз в 20 секунд.
- Отличается золотым цветом и увеличенным размером.
- Даёт очки по курсу золота и не зависит от выбранного скина.

### Рекорды и поворот экрана

- По окончании раунда результат сохраняется в Room.
- Сообщение показывает, установлен ли новый рекорд.
- При повороте экрана счёт и таймер не сбрасываются: игровое состояние хранится в `GameViewModel`.

## Запуск проекта

### Требования

- **Android Studio** - последняя стабильная версия (проект собран на AGP 9.4.1 / Gradle 9.6.0);
- **Android SDK** - API 37 (`compileSdk` и `targetSdk`), минимальная версия устройства - **Android 7.0 (API 24)**;
- **JDK** - 17 или новее. Android Studio использует встроенный JDK (JBR), отдельно устанавливать не нужно;
- **Android Emulator** или физическое устройство.

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/gromova-aan/Zhuki_Game.git
```

### 2. Откройте проект в Android Studio

`File` → `Open` → выберите корневую папку `Zhuki_Game` (не вложенную `app`).

### 3. Создайте `local.properties`

В корне проекта создайте файл `local.properties` и укажите путь к SDK.

Windows:

```properties
sdk.dir=C\:\\Users\\<Ваше_Имя>\\AppData\\Local\\Android\\Sdk
```

macOS:

```properties
sdk.dir=/Users/<Ваше_Имя>/Library/Android/sdk
```

Путь можно посмотреть в Android Studio: `File` → `Project Structure` → `SDK Location`.

### 4. Синхронизируйте Gradle

`File` → `Sync Project with Gradle Files`.

### 5. Установите недостающие SDK (при необходимости)

`Tools` → `SDK Manager` → отметьте **Android SDK Platform 37** и нужные инструменты → `Apply`.

### 6. Запустите приложение

- Создайте эмулятор: `Tools` → `Device Manager` → `Create Virtual Device`;
- выберите устройство с API 24+ и образом без Google Play, если эмулятор работает нестабильно;
- нажмите `Run` или `Shift + F10`.

Для физического устройства включите «Отладку по USB» в настройках разработчика и подтвердите подключение.

### Запуск из терминала

Windows:

```powershell
cd D:\AndroidStudioProjects\Zhuki_Game

# если JAVA_HOME не настроен — используйте JDK из Android Studio
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"

.\gradlew.bat assembleDebug
```

macOS / Linux:

```bash
cd Zhuki_Game
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённое устройство:

```powershell
.\gradlew.bat installDebug
```
